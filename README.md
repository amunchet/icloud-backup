# ICloud Gitlab sync
This is a Gitlab - ICloud Sync (for Obsidian, but could be for anything).

## 2FA Errors
1. Enable the venv (look at `run.sh` for the exact command - usually something like `source .venv/bin/activate`)
2. Run `icloud --username=[XXXXX]`.  This might prompt for a password (probably) or the 2FA code on your device.

## Gitlab Errors
The Gitlab key will expire in a year.  This is annoying but probably a good thing.
